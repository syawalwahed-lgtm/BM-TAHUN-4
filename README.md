# 🚀 Jelajah Tatabahasa Tahun 4

Bahan digital interaktif Bahasa Melayu Tahun 4 (Tatabahasa) untuk:
- Guru: Syawal
- Sekolah: SK (P) Jalan Yahya Awal
- 20 soalan kuiz dengan markah dan maklum balas automatik
- Nota ringkas berdasarkan Aspek Tatabahasa DSKP BM Tahun 4
- QR code automatik berdasarkan URL halaman semasa

## Cara terbitkan menggunakan GitHub Pages

1. Cipta satu repository baharu di GitHub, contoh: `bm-tahun4-tatabahasa`.
2. Muat naik fail `index.html` ke repository tersebut.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, kemudian **Save**.
6. GitHub akan memberikan URL GitHub Pages, biasanya:
   `https://NAMA-GITHUB.github.io/bm-tahun4-tatabahasa/`
7. Buka URL tersebut. QR code dalam bahan akan menjana QR yang menghala ke URL halaman itu.

## Nota
QR menggunakan perkhidmatan QR Server melalui internet. Jika sekolah menyekat akses perkhidmatan tersebut, bahan dan kuiz masih boleh digunakan; hanya imej QR mungkin tidak dipaparkan.
